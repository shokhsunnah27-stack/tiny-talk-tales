# Tiny Talk Tales

ছোটদের ইংরেজি শেখার গল্প-ঘর। এটি একটি সাধারণ HTML, CSS ও JavaScript ওয়েবসাইট। কোনো build বা install লাগে না, তাই সরাসরি GitHub Pages-এ চলে।

## ফোল্ডার কাঠামো

```
tiny-talk-tales/
├── index.html          মূল পেজ (এটি অবশ্যই রুটে থাকতে হবে)
├── .nojekyll           GitHub Pages-কে জানায় সাইটটি সরাসরি পরিবেশন করতে
├── README.md           এই নির্দেশনা
├── css/
│   ├── style.css       মূল স্টাইল
│   └── playful.css     রং, হোভার ইফেক্ট, অ্যানিমেশন, প্রোফাইল সেকশনের স্টাইল
├── js/
│   ├── site-data.js    আপনার নিজের তথ্য (ফোন, ইমেইল, মূল্য, মতামত)
│   ├── main.js         সাইটের সব কাজ (শব্দ শোনা, গল্প, ABC ব্লক, ফিল্টার ইত্যাদি)
│   └── fun.js          ক্লিকে রঙিন কনফেটি ও ABC অক্ষরের রং বদল
└── assets/
    ├── brand.jpg       "আমাদের পরিচয়" সেকশনের বড় ব্র্যান্ড ছবি
    ├── avatar.jpg      হেডার ও ফুটারের গোল প্রোফাইল ছবি (ব্র্যান্ড ছবি থেকে কাটা ভালুকের মুখ)
    └── favicon.svg     ব্রাউজার ট্যাবের আইকন
```

শব্দ-কার্ডের ছবি আর গল্পের দৃশ্য কোডের ভেতরে SVG হিসেবে আছে, তাই সেগুলোর আলাদা ফাইল নেই। ফন্ট (Anek Bangla, Noto Sans Bengali, Fraunces) Google Fonts থেকে লোড হয়, এজন্য ভিজিটরের ইন্টারনেট লাগবে।

## GitHub-এ কী কী আপলোড করবেন

`tiny-talk-tales` ফোল্ডারের **ভেতরের সবকিছু** আপলোড করুন (ফোল্ডারটি নিজে নয়, যাতে `index.html` রিপোজিটরির রুটে থাকে):

- `index.html`
- `css/` ফোল্ডার (`style.css`, `playful.css`)
- `js/` ফোল্ডার (`site-data.js`, `main.js`, `fun.js`)
- `assets/` ফোল্ডার (`brand.jpg`, `avatar.jpg`, `favicon.svg`)
- `.nojekyll`
- `README.md` (ঐচ্ছিক)

`.nojekyll` একটি লুকানো ফাইল, ফোল্ডারে না দেখালে চিন্তা নেই। এই সাইটে এটি ছাড়াও সব ঠিকঠাক চলবে।

## GitHub Pages-এ Hosting (ধাপে ধাপে)

### পদ্ধতি ১: ব্রাউজার থেকে (সবচেয়ে সহজ)

1. github.com-এ লগইন করে **New repository** চাপুন।
2. নাম দিন, যেমন `tiny-talk-tales`। **Public** বেছে নিন এবং **Create repository** চাপুন।
3. নতুন রিপোজিটরির পেজে **uploading an existing file** লিংকে ক্লিক করুন।
4. উপরের তালিকার সব ফাইল ও ফোল্ডার টেনে এনে ছাড়ুন। আপলোড শেষ হলে **Commit changes** চাপুন।
5. রিপোজিটরির **Settings → Pages** এ যান।
6. **Build and deployment → Source** এ **Deploy from a branch** বেছে নিন।
7. **Branch** হিসেবে `main` এবং ফোল্ডার `/ (root)` বেছে **Save** চাপুন।
8. ১–২ মিনিট অপেক্ষা করুন। Pages পেজের উপরে সাইটের লিংক দেখা যাবে।

### পদ্ধতি ২: Git কমান্ড দিয়ে

```bash
cd tiny-talk-tales
git init
git add .
git commit -m "Tiny Talk Tales first version"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/tiny-talk-tales.git
git push -u origin main
```

এরপর উপরের ধাপ ৫–৮ অনুসরণ করুন।

## নিজের তথ্য বসানো

ফোন, ইমেইল, Facebook, YouTube, মূল্য বা প্যাকেজ এবং অভিভাবকদের মতামত বসাতে `js/site-data.js` ফাইল খুলুন। `[ ]` চিহ্নের ভেতরের লেখাগুলো নমুনা, এগুলো বদলে আপনার তথ্য দিন। GitHub-এ ফাইলটি খুলে পেনসিল আইকনে চাপলে সরাসরি এডিট করে Commit করা যায়। কয়েক মিনিট পর সাইটে পরিবর্তন দেখা যাবে।

## প্রোফাইল ছবি বদলানো

- বড় ছবি: `assets/brand.jpg` ফাইলটি একই নামে নতুন ছবি দিয়ে বদলে দিন (বর্গাকার ছবি সবচেয়ে ভালো দেখায়)।
- হেডারের গোল ছবি: `assets/avatar.jpg` একই নামে বদলান (প্রায় ২০০×২০০ পিক্সেলের বর্গাকার ছবি যথেষ্ট)।
- ছবির সাইজ ৫০০ KB-এর নিচে রাখলে সাইট দ্রুত খুলবে।

## রং ও অ্যানিমেশন বন্ধ করতে চাইলে

`index.html`-এ `css/playful.css` ও `js/fun.js` যে দুই লাইনে আছে, সেই দুই লাইন মুছে দিলে সাইট আগের শান্ত লুকে ফিরবে। যাদের ডিভাইসে "reduce motion" চালু আছে, তাদের জন্য অ্যানিমেশন নিজে থেকেই বন্ধ থাকে।

## জানা থাকা ভালো

- "ভিডিও" কার্ডে ক্লিক করলে এখন "ভিডিওটি শীঘ্রই চালু হচ্ছে" বার্তা আসে। আসল ভিডিও যোগ করা হলে এই আচরণ বদলাতে হবে।
- শব্দ শোনার সুবিধা ব্রাউজারের নিজস্ব Text-to-Speech ব্যবহার করে। কিছু পুরনো ব্রাউজারে এটি কাজ নাও করতে পারে।
- "বার্তা তৈরি করুন" ফর্ম কোথাও কিছু পাঠায় না। এটি শুধু বার্তা বানিয়ে কপি করার সুযোগ দেয়।
